Политика конфиденциальности приложения yts-channels

Действует с 17 октября 2026 года.

yts-channels — служебное приложение автора нескольких YouTube-каналов. Оно используется только владельцем этих каналов: доступ запрашивается у его аккаунта Google и у каналов бренда, которыми он управляет.

Какие данные приложение получает

После согласия владельца канала в окне Google приложение получает доступ к YouTube Data API и YouTube Analytics API в пределах запрошенных разрешений:

  • загрузка видео на канал и изменение его собственных видео (название, описание, статус, закреплённый комментарий);
  • чтение статистики канала: просмотры, удержание, источники трафика, обобщённые данные об аудитории.

Приложение не получает доступ к данным других пользователей YouTube, кроме обобщённой статистики канала, которую показывает YouTube Analytics.

Как данные используются

Данные используются только для публикации видео каналов по расписанию и для отчётов автору о том, как работают его ролики. Они не продаются, не передаются третьим лицам и не используются для рекламы.

Использование и передача информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Хранение

Токены доступа хранятся в зашифрованном виде на сервере автора, отдельно для каждого канала. Статистика каналов хранится там же и доступна только автору.

Как отозвать доступ

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions. После отзыва приложение перестаёт работать с каналом; сохранённый токен удаляется вместе с настройками канала.

Контакты

Вопросы по этой политике можно задать автору через раздел «О канале» на странице соответствующего канала на YouTube.
