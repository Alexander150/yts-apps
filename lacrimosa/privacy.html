Политика конфиденциальности приложения yts-lacrimosa

Действует с 23 октября 2026 года.

yts-lacrimosa — служебное приложение YouTube-канала LACRIMOSA. Оно предназначено только для этого канала и используется только его владельцем.

Какие данные приложение получает

После того как владелец канала даёт согласие в окне Google, приложение получает доступ к YouTube Data API и YouTube Analytics API в пределах запрошенных разрешений:

  • загрузка видео на канал и изменение его собственных видео (название, описание, статус, закреплённый комментарий);
  • чтение статистики канала: просмотры, удержание, источники трафика, обобщённые данные об аудитории.

Приложение не получает доступ к данным других пользователей YouTube, кроме обобщённой статистики канала, которую показывает YouTube Analytics.

Как данные используются

Данные используются только для публикации видео по расписанию и для отчётов владельцу о том, как работают ролики. Они не продаются, не передаются третьим лицам и не используются для рекламы.

Использование и передача информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Хранение

Токен доступа хранится в зашифрованном виде на сервере автора. Статистика канала хранится там же и доступна только владельцу.

Как отозвать доступ

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions. После отзыва приложение перестаёт работать с каналом; сохранённый токен удаляется вместе с настройками канала.

Контакты

Вопросы по этой политике можно задать через раздел «О канале» на странице канала LACRIMOSA на YouTube.
